## 🚀 Comment Lancer le Projet

1. Double-cliquez simplement sur le fichier `index.html` pour l'ouvrir dans n'importe quel navigateur (Google Chrome, Edge, Firefox, Safari).
2. Ou servez le dossier avec n'importe quel serveur local (ex: extension VS Code *Live Server*, ou `python -m http.server 8000`).
